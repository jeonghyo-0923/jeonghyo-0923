<h2 style="border-bottom: 1px solid #21262d; color: #c9d1d9;"> 👋 Introduction </h2>
<div style="font-weight: 700; font-size: 15px; text-align: left; color: #c9d1d9;">

드론·유인기 기반 항공영상을 활용해 해양 수색구조(SAR) 및 재해대응 딥러닝 모델을 연구하는 공간정보공학 석사입니다.<br/>
서울시립대학교 LSM연구실에서 조난 선박 탐지, 악천후 강건 탐지, 헬기영상 자동보정 등을 주제로 <b>논문 14편, 소프트웨어 6건, 특허 1건</b>을 발표·개발했습니다.

<h2 style="border-bottom: 1px solid #21262d; color: #c9d1d9;"> 💼 Career </h2> <br>

**서울시립대학교 LSM연구실** &nbsp;·&nbsp; <sub>2023.02 - 현재</sub>

- **AI기반 해양수색구조 의사결정지원시스템 개발** (해양수산과학기술진흥원, 2022-2026)
  - 드론·유인기 기반 해양 수색구조(SAR) 조난 선박 탐지 딥러닝 모델을 연구·개발 (논문 12편, 소프트웨어 5건)
  - 안개 등 악천후 환경에서의 선박 탐지 성능 개선 연구를 수행하고 IEEE IGARSS 2025 등 국제 학술대회에서 발표
  - 특허 1건 출원 (2025)
- **산불 화선 자동 탐지 및 시스템 연계 기술 개발** (한국임업진흥원, 2025~2029)
  - 표정요소(GCP)가 부재한 헬기 영상을 대상으로 자동 GCP 추출 및 정사보정(georeferencing) 프로그램 개발
  - 멀티모달 대형언어모델(MLLM) 기반 선박 속성 추출 및 지오로케이션 융합 기술을 연구해 ISPRS 2026 논문 게재
- 해양오염사고 현장탐색자료를 활용한 오염정보 자동생성 및 표출기술 개발 (2020-2023)
- 위성연계 접경수역 선박 모니터링 및 분포 예측 체계 개발 (해양수산과학기술진흥원, 2020-2023)
